# Честное колесо

Веб-приложение колеса выбора на React, TypeScript и Vite. Финальный сектор выбирается криптографическим модулем из `randomEngine.ts`; визуальная анимация только показывает уже выбранный результат.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Режимы

- **На выбывание** — выпавший вариант автоматически вычёркивается, пока не останется один.
- **Один выбор** — варианты остаются на колесе; победителя можно вычеркнуть вручную.

На широком экране ширину правой панели можно менять, потянув за её левую границу (или стрелками, когда ползунок в фокусе). Панель ограничена безопасной минимальной и максимальной шириной, поэтому колесо нельзя полностью закрыть. Прокрутка остаётся внутри панели, а подвал всегда виден.

Горячие клавиши: `Space` запускает колесо, физическая клавиша `S` зачёркивает текущего победителя (раскладка клавиатуры значения не имеет).

Внешняя энтропия включена по умолчанию. При её отключении используется быстрый offline-режим на Web Crypto. GPS, камера и микрофон подключаются только отдельными переключателями и требуют разрешения браузера.
